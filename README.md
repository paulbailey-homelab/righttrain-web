# RightTrain Web

The public website and status page for [RightTrain](https://righttrain.app): a small Svelte
5 + Vite single-page app served by nginx. It shows shared journey links, the public
service-status page and the App Store entry point, and talks to the RightTrain API over HTTP.

The backend is a separate private repository and the iPhone app is
[`righttrain-ios`](https://github.com/paulbailey-homelab/righttrain-ios).

## Develop

```bash
npm ci
npm run dev      # Vite dev server
npm run build    # production build into dist/
```

Node 24 (see `.nvmrc`). The API location is runtime configuration, not baked into the build:
`public/runtime-config.js` is replaced at container start from the `API_BASE_URL`,
`PUBLIC_WEB_BASE_URL` and `RIGHTTRAIN_APP_STORE_URL` environment variables
(`docker-entrypoint.d/40-runtime-config.sh`).

## Image and deploy

`Dockerfile` builds the static site into an nginx image. Releases are tags:

```bash
git tag v0.1.1 && git push origin v0.1.1
```

The `Publish Image` workflow builds `ghcr.io/paulbailey-homelab/righttrain-web:<version>` and
commits the new tag into `deploy/homelab/values-homelab.yaml`. The cluster's Argo CD
application reads the chart in `deploy/helm/righttrain-web` and that values file straight from
this repository, so a release needs no commit anywhere else.

The chart deploys two copies of the image: the main site and a status page on its own host.
Both ingresses route a few API paths (`/v1/journey-shares`, `/v1/status`) to the backend
Service named in `apiService` (default `clearsignal-api`), which must exist in the same namespace.

## Contracts with the other repositories

- **Backend API**: the TypeScript types in `src/lib/types/api.ts` are hand-written against the
  backend's OpenAPI contract; an API change needs a matching change here.
- **iOS universal links**: `public/.well-known/apple-app-site-association` must list the app's
  team and bundle identifiers as configured in `righttrain-ios`.
- **Icons**: `public/icons/` is generated by `scripts/generate-righttrain-icons.swift` in
  `righttrain-ios` (it writes here when this repo is checked out next to it).
